# Marketing Impact Lab

Marketing Impact Lab is a live portfolio analytics project built around my personal website, [quinnreams.com](https://www.quinnreams.com).

## Project Goal
The purpose of this project is to test how intentional marketing actions — such as LinkedIn posts, portfolio updates, and CTA changes — affect traffic and engagement on my site.

Rather than treating my portfolio like a static website, I am using it as a live sandbox to practice marketing measurement, experimentation, and performance analysis.

## Core Questions
- Which channels drive traffic to my portfolio?
- Which actions increase engagement?
- Do certain experiments lead to more resume, GitHub, or email clicks?
- How can low-traffic data still support useful analysis?

## Current Tracking
- GA4 page views
- GA4 outbound click tracking
- Session source / medium analysis
- Campaign tagging with UTM parameters
- Daily metrics logging
- Baseline vs experiment comparisons

## Week 1 Experiment
**Experiment Name:** `Week1_LinkedIn_Activation`

**Focus:** Establish a baseline and test whether LinkedIn posts can drive measurable traffic and engagement.

**Primary Metric:** Sessions  
**Secondary Metrics:** Project page views, resume clicks, GitHub clicks, email clicks

## Project Structure
- `data/` → daily tracking dataset
- `reports/` → weekly findings and experiment summaries
- `planning/` → experiment plans, naming conventions, and LinkedIn drafts
- `docs/` → methodology and logging rules
- `assets/` → screenshots and visuals

## Method
This project uses a simple weekly experiment structure:
1. Establish a baseline
2. Run one focused test
3. Measure traffic and engagement in GA4
4. Compare baseline vs experiment period
5. Document findings and next steps

## Current Status
Project setup is in progress. The first experiment is focused on LinkedIn-driven traffic and early engagement measurement.

## Notes
Because traffic volume is currently low, early results should be interpreted as directional rather than definitive. The focus of this project is on building a disciplined measurement and experimentation process.
