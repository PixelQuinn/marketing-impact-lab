# Weekly Test Plan

## Week 1
**Focus:** Natural baseline collection

### Goal
Establish a realistic pre-experiment baseline for traffic and engagement on quinnreams.com.

### Actions
- Log completed daily metrics from GA4
- Track sessions by source / medium
- Track project page views
- Track project clicks, GitHub clicks, resume clicks, and email clicks
- Save supporting screenshots by date

### Output
- Completed baseline dataset
- Baseline summary report
- Experiment setup for Week 2 LinkedIn activation
